# Портфолио аналитика данных

Разрабатываю аналитические решения на Python, SQL и Yandex DataLens: готовлю и исследую данные, рассчитываю продуктовые и коммерческие метрики, проверяю статистические гипотезы и создаю интерактивные дашборды.

В проектах работала с пользовательской активностью, конверсией, retention, транзакциями, средним чеком, сезонностью и сегментацией. Основное направление — аналитика данных и BI; дополнительная специализация — продуктовая аналитика и A/B-тестирование.

## Навыки

**SQL:** PostgreSQL, CTE, JOIN, оконные функции, CASE-сегментация, перцентили, условная агрегация, работа с датами.

**Python:** pandas, NumPy, Matplotlib, Seaborn, SciPy, statsmodels, phik, Jupyter Notebook.

**BI:** Yandex DataLens, вычисляемые поля, KPI, селекторы, QL-чарты, временные ряды, детализация и условное форматирование.

**Аналитика:** EDA, проверка качества данных, продуктовые метрики, когортный анализ, A/B-тестирование, Z-тест пропорций, t-тест Уэлча, U-тест Манна—Уитни.

## Как читать проекты

В каждой папке представлены постановка задачи, этапы анализа, результаты, рекомендации и ограничения. Для проектов доступны ноутбуки, SQL-скрипты или скриншоты дашбордов.

Все выводы относятся к использованным учебным или историческим данным. Статистические связи не интерпретируются как причинные без соответствующего дизайна исследования.
